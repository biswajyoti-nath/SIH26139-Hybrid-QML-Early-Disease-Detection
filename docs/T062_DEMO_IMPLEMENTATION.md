# T-062 Demo Implementation

## Files Created
- `backend/core/complexity_profiler.py`: Lightweight profiler for extracting descriptive characteristics ($R_k$, $L_k$, $C$, $S$, $\rho$).
- `backend/core/suitability_router.py`: Rule-based router implementing the logic to choose between Classical, Quantum Promising, Statistically Comparable, and Inconclusive.
- `backend/api/main.py`: Minimal FastAPI backend exposing endpoints for the demo UI.
- `frontend/src/App.tsx` & `App.css`: Minimal React dashboard built with Vite.

## Router Logic & Thresholds
The current router is a transparent rule-based research prototype. Its thresholds are not scientifically validated and require future validation on additional datasets.
- `MIN_QUANTUM_DELTA`: 0.01
- `MAX_ACCEPTABLE_RUNTIME_RATIO`: 100.0
- `MIN_VARIANCE_RETENTION`: 0.50

## Result Artifacts Consumed
The demo runs entirely in **DEMO MODE**. It consumes the cached JSON artifacts generated during the T-103 Quantum Model Shootout:
- `exp_t103_shootout_wdbc_1788680280.json`
- `exp_t103_shootout_parkinsons_1788682249.json`

## Known Limitations & Reality Map
- **What is real:** The ROC-AUC metrics, the PCA variance drops, the runtimes, and the correlation profiles are real empirical evidence generated by our execution engine on local hardware.
- **What is cached:** The actual training of the quantum circuits is bypassed in the demo to allow instantaneous presentation.
- **Future Work:** Replacing the heuristic rule-based router with a statistically calibrated decision engine, and transitioning off simulators to real QPUs when hardware constraints allow.

## Discrepancies Noted During UI Audit
- **Parkinson's QSVM ROC-AUC:** The `docs/T103_QUANTUM_SHOOTOUT_REPORT.md` lists `0.504`. The actual cached JSON artifact value is `0.5048282...`, which rounds to `0.505`. The UI accurately displays the authoritative artifact value (`0.505`).
- **Parkinson's PCA Variance Retention:** The original dynamic PCA calculation in `complexity_profiler.py` was producing `46.2%` due to unscaled feature execution. The API was updated to pull the authoritative fold-wise mean variance retention directly from the T-103 JSON artifact (`47.0%`), which corrects the UI consistency while ensuring no experimental manipulation occurs.
